## control-API (фаза-1 — ✅ DELIVERED)

> Реализован `cmd/control-api` (Go stdlib). Гейты: `go build`/`vet`/`test` (5 httptest) + live `curl` smoke (healthz / POST-403 / bad-target-400 / CORS-preflight-204) — зелёные. Docker `control-api` profile (порт `127.0.0.1:8090`). ADR-032 в ARCHITECTURE §3.


Тонкий **Go HTTP-сервис** (`cmd/control-api`, stdlib `net/http`, как M8 report-service — без новых зависимостей).
Это «не-MCP» путь; MCP-путь (M7) сосуществует (ADR-023).

**Эндпоинты (v1):**
| Метод | Путь | Назначение |
|---|---|---|
| GET | `/healthz` | liveness (без auth) → `{status:"ok", version}` |
| GET | `/v1/config-schema` | поверхность RunConfig (для WebUI) — ключи/дефолты из `runconfig.py`/флагов |
| POST | `/v1/runs` | старт прогона из `{target, runConfig|mode/goal/describe/planner/budgets/auth, env?}` → `{run_id}` (спавнит `agentctl run …`, как orchestrator) |
| GET | `/v1/runs/{id}` | статус: `{state: running|done|failed, exit_code, artifact_dir}` |
| GET | `/v1/runs` | список последних прогонов |

**Безопасность (ADR-032):**
- **Bind на `127.0.0.1` по умолчанию** (`CONTROL_API_ADDR`, не `0.0.0.0` без явного согласия) — спавн
  прогонов = чувствительная поверхность (RCE-класс при публичной экспозиции).
- **Bearer-token** (`CONTROL_API_TOKEN`) обязателен для мутаций (`POST /v1/runs`); `/healthz` — открыт.
  Без токена в env — мутации **403** (read-only/health only).
- **CORS-allowlist** (`CONTROL_API_CORS_ORIGINS`, напр. `https://alexgromer.github.io,http://localhost:8088`):
  ⇒ **Pages-страница может драйвить ЛОКАЛЬНЫЙ control-API** (localhost — исключение mixed-content + CORS).
  По умолчанию — пусто (CORS off; только same-origin/бандл).
- Спавн только через известный путь `agentctl` + валидация входа (никаких произвольных команд).

## M9.3-tail — чат-фронт + стриминг + artifact-fetch (✅ DELIVERED, ADR-040)

> Хвост M9.3 (GAP-M9-03/12 + частично GAP-M9-14). Решения по трём развилкам:

**Чат-фронт = кастомный vanilla `docs/chat/index.html` (НЕ Open WebUI).** brain **не разговорный**:
M7 MCP-сервер отдаёт только `explore/heal/replay/report` (stdio + host-`sampling`), а describe-режим
строго **one-shot** (одна NL-строка → один `scenario.json` → выход). Open WebUI требует OpenAI-совместимый
`/v1/chat/completions` ИЛИ mcpo-фронтуемый tool-сервер с host-sampling — brain не даёт ни того, ни другого;
интеграция = новый тяжёлый адаптер, ломающий air-gapped-этос. Поэтому — самодостаточный sibling setup-WebUI:
inline style+script, системные шрифты, без CDN, `file://`-safe; **bilingual** (`data-lang`/`setLang`,
localStorage `sentinel_lang`); честный «чат-стиль авторинга» (не мульти-тёрн — UI это проговаривает).
Поток: описать (target + mode `describe|goal|explore` + NL) → `POST /v1/runs` (202) → **SSE**-стрим прогресса
→ по `done` показать/скачать `scenario.json`/отчёт. Fallback на 2с-poll если SSE недоступен. Отдаётся
существующим профилем `webui` на `:8088/chat/` (нового профиля нет — статика под `/app/docs`).

**Стриминг = SSE, не WS (ADR-040).** control-API расширен (stdlib, без новых зависимостей):
- `GET /v1/runs/{id}/events` — **SSE, token-gated**: `event: state` (running|done|failed + exit_code),
  `event: log` (stdout/stderr прогона из capped ring-buffer — реплей при подключении + live), терминальный
  `event: done`. Вывод прогона захватывается в per-run ring-buffer + fan-out подписчикам.
- `GET /v1/runs/{id}/artifact?name=<f>` — **token-gated**, отдаёт whitelisted-файл из `artifact_dir`
  (`scenario.json`/`reconcile-report.json`/`report.json`/`report.html`/`plan.json`; guard на `/`·`..`; 404 если нет).
- **Почему SSE, не WS:** WebSocket потребовал бы не-stdlib зависимость / ручной RFC6455 — нарушает stdlib-only
  принцип control-API (как M8 report-service). **GAP-M9-14 закрыт ЧАСТИЧНО:** server→client живой канал есть;
  client→server канал рекордера расширения (WS *или* native-messaging) — решение **M9.8-impl**.
- Безопасность: events/artifact под тем же bearer-токеном, что мутации (логи/артефакты чувствительнее статуса);
  переиспользует localhost-bind + CORS-allowlist (ADR-032).

**CI-шаблоны = `docs/ci-templates/` (✅).** `Jenkinsfile` + `.gitlab-ci.yml` + bilingual `README.md`/`.en.md`.
Маппинг exit-кодов (verify: `cmd/agentctl/main.go:10`, `M3_CONTRACT.md`, `TESTING.md:354`): **0** pass · **1**
step-fail (assertion / непокрытый describe = «тест нашёл проблему») · **2** golden/visual регрессия · **3**
plan-integrity / config-ошибка (нужен человек). В CI: 0→success; 1/2→failure; 3→unstable. Это **пользовательские**
шаблоны, не наши `.github/workflows/`.

**Вне scope (отложено):** replay-через-control-API endpoint (подать готовый `scenario.json` на детерминированный
повтор) — минимизирует sensitive spawn-поверхность; петля describe→авторинг+прогон-за-один-шаг + показ/скачивание
уже полна.
