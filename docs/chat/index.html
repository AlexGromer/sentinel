Sentinel — чат-консоль авторингаchat-authoring console

Статический клиент (vanilla JS, без сервера и сети — работает offline / air-gapped). «Чат» здесь — консоль авторинга поверх локального control-API: опиши тест словами → агент авторит сценарий и запускает прогон → прогресс стримится → готовый scenario.json можно скачать. Это не мульти-тёрн LLM-чат: brain отрабатывает один проход (описание → один scenario.json → выход), каждое сообщение = один цикл авторинга/прогона. Static client (vanilla JS, no server, no network — works offline / air-gapped). "Chat" here is an authoring console over a local control-API: describe a test in words → the agent authors a scenario and runs it → progress streams in → download the resulting scenario.json. This is not a multi-turn LLM chat: the brain runs one pass (description → one scenario.json → exit), so each message = one authoring/run cycle.

ПодключениеConnection

С GitHub Pages «живой» режим работает только против http://localhost (исключение mixed-content); control-API должен слать CORS на этот origin (CONTROL_API_CORS_ORIGINS). Из бандла (docker compose --profile control-api up) ограничения нет. Токен хранится только в этой вкладке (в памяти), никогда — в URL/конфиге. From GitHub Pages, live mode only works against http://localhost (mixed-content exemption); the control-API must emit CORS for that origin (CONTROL_API_CORS_ORIGINS). From the bundle (docker compose --profile control-api up) there is no such limit. The token is kept only in this tab (in memory), never in the URL/config.
