## Documentation language
Docs are **bilingual**: every `*.md` is the **Russian primary (authoritative)** version and
carries a paired `*.en.md` English copy (e.g. `README.md` ↔ `README.en.md`). Each file links to
its counterpart via a `🌐` banner on line 3. Edit the `.md` first, then mirror into `.en.md`.
(`FILEMAP.md` and `BACKLOG.md` are working files — kept single-language.)

> ⚠ Строки с пометкой **INTERNAL-ONLY, gitignored** называют файлы, которых в клоне и в `git archive` НЕТ. Это указатель для того, кто работает в исходном дереве, а не обещание файла; их содержание в этом индексе не пересказывается сознательно.

## Build / run
- gateway-aware: `go build -o bin/agentctl ./cmd/agentctl && go build -o bin/store-gateway ./cmd/store-gateway` (if /tmp full: `go env -w GOTMPDIR=/opt/go/tmp`)
- TS: `cd pw-executor && npm install && npm run build` (`npx playwright install chromium-headless-shell`)
- Py: `uv venv && uv pip install langgraph langgraph-checkpoint-sqlite anthropic openai grpcio grpcio-tools`
- gRPC stubs (regen): `.venv/bin/python -m grpc_tools.protoc -I proto --python_out=brain/pb --grpc_python_out=brain/pb proto/persistence.proto proto/runcontrol.proto proto/store.proto` — then rewrite the generated top-level imports to package-relative: `sed -i -E 's/^import (persistence_pb2\|store_pb2) as /from . import \1 as /' brain/pb/store_pb2.py brain/pb/store_pb2_grpc.py brain/pb/persistence_pb2_grpc.py` (note `store_pb2.py` needs it too — it imports `persistence_pb2`). Go: same `grpc_tools.protoc` (it bundles `protoc`; the standalone binary is not installed) with `--plugin=protoc-gen-go=/opt/go/bin/protoc-gen-go --plugin=protoc-gen-go-grpc=/opt/go/bin/protoc-gen-go-grpc --go_out=internal/store/pb --go_opt=paths=source_relative --go-grpc_out=internal/store/pb --go-grpc_opt=paths=source_relative`. **Before editing a .proto, regenerate the UNCHANGED one into a temp dir and diff** — it proves the toolchain matches the checked-in stubs (Go is byte-identical; Python differs only by the import patch above)
